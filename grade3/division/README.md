# Division Made Easy — 3rd Grade

`Division_Made_Easy_Grade3.pdf` is a printable, 37-page book: one hands-on lesson to learn division
today, then 10 days of practice and reprintable extra practice.

| Pages | What |
|---|---|
| 1–4 | Cover, today's lesson plan, what to do/say in each part, 10-day practice plan + games |
| 5–7 | "What does ÷ mean?" poster, times table used backwards, tracker |
| 8–14 | Today's lesson: 6 worksheets (sharing, grouping, arrays, think multiplication, number line, stories) |
| 15–25 | 10 practice days (with times-table helper strips on days 1–4) |
| 26–34 | 6 Mad Minute sheets + division flash cards |
| 35–37 | Certificate, answer key |

Rebuild: `python3 build.py` (needs `reportlab`; shared helpers live in `common/printkit.py`).
