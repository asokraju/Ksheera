| Book | Folder |
|---|---|
| Rudhra's Word Workshop — 3-letter words | [cvc_words/](cvc_words/) |
| *(next)* Addition & subtraction | |

Each book lives in its own folder with a `build.py`. Pictures for this age come from `common/icons.py`
(`ICONS["bus"](c, x, y, size)` and ~55 more); `common/printkit.py` has the page layout helpers.

Tips for this age: big print, lots of pictures, few items per page, trace/circle/connect instead of
writing, and 10–15 minute sessions.
