# Kindergarten books

Put each kindergarten book in its own folder here, e.g. `kindergarten/counting/build.py`,
following the steps in the top-level README. `common/printkit.py` already has kid-friendly pictures
(cookies, plates, stars, dot groups, arrays, number lines) that work well for this age.

Tips for this age: big fonts (20pt+), lots of pictures, few problems per page, trace/circle/color
activities instead of writing, and very short sessions (10–15 minutes).
