# Multiplication Mastery — 3rd Grade (4-week plan)

`Multiplication_Mastery_Grade3.pdf` is a printable, 52-page learn-and-practice book for a 3rd grader
who already knows the 1–10 times tables.

| Pages | What |
|---|---|
| 1–7 | Cover, parent guide (daily routine, tips), 4-week plan, day-by-day teaching notes, games |
| 8–10 | Strategy poster, multiplication chart, progress tracker |
| 11–37 | 20 daily worksheets (Weeks 1–4) incl. 2-page final test |
| 38–49 | Extra practice: 8 Mad Minute sheets, fold-over flash cards, bingo |
| 50–52 | Certificate, answer key |

Rebuild (fixed random seeds keep the answer key in sync): `python3 build_book.py` (needs `reportlab`).
